Introduction to CSS

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML or XML. It allows you to control the layout, colors, fonts, and overall appearance of your web pages.

Basic Syntax

CSS rules consist of a selector and a declaration block. The selector specifies which HTML elements the rule applies to, while the declaration block contains one or more declarations separated by semicolons. Each declaration includes a property and a value.

Example

        h1 {
            color: blue;
            font-size: 24px;
        }

In this example, the selector is "h1", which targets all <h1> elements. The declarations set the text color to blue and the font size to 24 pixels.
